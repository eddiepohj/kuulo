**Goal:** A personal sound level meter and spectrum analyser PWA (Meter, Spectrum, Calibrate) for the iPhone home screen, served from GitHub Pages.

### Task 2: `weighting.js` — A/C curves and biquad design

**Files:**
- Create: `js/weighting.js`
- Test: `tests/weighting.test.js`

**Interfaces:**
- Produces:
  - `curve(type: 'A'|'C'|'Z', f: number) → number` dB, IEC 61672 analytic, 0 dB at 1 kHz (A uses +2.00, C uses +0.06 normalisation).
  - `design(type: 'A'|'C'|'Z', sampleRate: number) → Array<{b0,b1,b2,a1,a2}>` cascaded biquads, a0 normalised to 1, difference equation `y = b0·x + b1·x1 + b2·x2 − a1·y1 − a2·y2`. `'Z'` → `[]`. Overall gain normalised so the response at 1 kHz is exactly 0 dB.
  - `responseDb(sections, f, sampleRate) → number` magnitude of the cascade at `f` in dB (`[]` → 0).

**Design method (use this; the tests decide):** pole frequencies `f1 = 20.598997`, `f2 = 107.65265`, `f3 = 737.86223`, `f4 = 12194.217` Hz, `w = 2π·f`, `K = 2·fs`.
- First-order high-pass via bilinear: `s/(s+w) → K(1 − z⁻¹) / ((K+w) − (K−w)z⁻¹)`.
- First-order low-pass via bilinear: `w/(s+w) → w(1 + z⁻¹) / ((K+w) − (K−w)z⁻¹)`.
- First-order low-pass via matched-z: `p = exp(−w/fs)`, `(1−p)/(1 − p·z⁻¹)`.
- **A** = HP(f1)·HP(f1) | HP(f2)·HP(f3) | LP_bilinear(f4)·LP_matched(f4) → 3 biquads (multiply the two first-order sections' polynomials to get each biquad).
- **C** = HP(f1)·HP(f1) | LP_bilinear(f4)·LP_matched(f4) → 2 biquads.
- Then scale the first section's b-coefficients so `responseDb(sections, 1000, fs) === 0`.
- Why the mixed f4 pair: bilinear alone reads ~0.3 dB low per pole at 8 kHz/48 kHz (frequency warping), matched-z alone ~0.35 dB high; one of each cancels to under 0.1 dB, and neither form needs `tan()` so it stays stable when f4 is above Nyquist (16 kHz Bluetooth mics). If the 0.5 dB test still fails at some frequency, fix the design, never the test.

### Task 3: `meter-worklet.js` — level meter DSP and processor

**Files:**
- Create: `js/meter-worklet.js`
- Test: `tests/meter.test.js`

**Interfaces:**
- Consumes: biquad section objects `{b0,b1,b2,a1,a2}` (from `design()` in Task 2; passed in, never imported — **no imports in this file**).
- Produces (named exports):
  - `MIN_DBFS = -120`
  - `toDbfs(meanSquare) → number` = `max(MIN_DBFS, 10·log10(2·meanSquare))`; `0` or negative → `MIN_DBFS`.
  - `createMeterState({ sampleRate, sections, sectionsA, response: 'F'|'S' }) → state`
  - `processBlock(state, input: Float32Array) → boolean` — processes samples, returns `true` when a post is due: ≥ 50 ms of samples since the last `readout()`, **or** a 1 s history period completed in this block (so no `secondLeq` is ever left unread).
  - `readout(state) → { level, leq, max, min, clipped, secondLeq?, secondLeqA? }` all dBFS; `secondLeq`/`secondLeqA` present only once per completed second (then cleared). Resets the 50 ms counter.
  - `setSections(state, sections)` (resets filter memory), `setResponse(state, 'F'|'S')`, `resetStats(state)` (Leq, Max, Min, elapsed, Min-delay restart; not the filter or time-weighted value).
  - Processor name `'kuulo-meter'`; registered only `if (typeof registerProcessor === 'function')`.
- Port protocol (used by Task 6): constructor `processorOptions = { sections, sectionsA, response }`; inbound messages `{type:'sections', sections}`, `{type:'response', response}`, `{type:'reset'}`; outbound `port.postMessage(readout(state))` whenever `processBlock` returns `true`. `numberOfInputs: 1, numberOfOutputs: 1, outputChannelCount: [1]`; the processor writes silence to its output and returns `true`.

**Per sample (spec §6.1):** weighted `y` through `sections` (selected weighting) and `yA` through `sectionsA` (always A, used for calibration); `ms += (y² − ms)·α`, `α = 1 − exp(−1/(τ·fs))`, τ = 0.125 (F) or 1 (S); Leq sums `y²` since reset; per-second sums of `y²` and `yA²`; clip if `|x| ≥ 0.99` on the raw sample, `clipped` true while fewer than `sampleRate` samples have passed since the last clip. After each block: `level = toDbfs(ms)`; Max/Min track `level`, Min only once ≥ 1 s of samples since reset/start. `max`/`min` before any value → `MIN_DBFS`.

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { MIN_DBFS, toDbfs, createMeterState, processBlock, readout, setResponse, resetStats } from '../js/meter-worklet.js';
import { design } from '../js/weighting.js';

const FS = 48000;
const close = (a, b, tol, msg) => assert.ok(Math.abs(a - b) <= tol, `${msg}: ${a} vs ${b}`);

function run(state, seconds, gen, t0 = 0) {
  const n = Math.round(seconds * FS);
  for (let i = 0; i < n; i += 128) {
    const blk = new Float32Array(128);
    for (let j = 0; j < 128; j++) blk[j] = gen((t0 + i + j) / FS);
    if (processBlock(state, blk)) readout(state);
  }
  return readout(state); // level at the end of the last processed block
}
const sine = (amp, f = 1000) => (t) => amp * Math.sin(2 * Math.PI * f * t);
const zMeter = (response = 'F') => createMeterState({ sampleRate: FS, sections: [], sectionsA: design('A', FS), response });

test('toDbfs: full-scale sine mean square 0.5 → 0 dBFS; zero → MIN_DBFS', () => {
  close(toDbfs(0.5), 0, 1e-9, 'fs sine');

  assert.equal(toDbfs(-1), MIN_DBFS);

test('full-scale 1 kHz sine reads 0.0 dBFS, 0.1 amplitude reads −20.0', () => {
  close(run(zMeter(), 1, sine(1)).level, 0, 0.1, 'full scale');
  close(run(zMeter(), 1, sine(0.1)).level, -20, 0.1, '0.1 amp');
});

test('A-weighted 1 kHz reads the same as Z', () => {
  const s = createMeterState({ sampleRate: FS, sections: design('A', FS), sectionsA: design('A', FS), response: 'F' });
  close(run(s, 1, sine(0.1)).level, -20, 0.1, 'A 1k');

test('Leq of 1 s at amp 1 then 1 s at amp 0.1 is the energy average', () => {
  const s = zMeter();
  run(s, 1, sine(1));
  const r = run(s, 1, sine(0.1), FS);
  close(r.leq, 10 * Math.log10(2 * (0.5 + 0.005) / 2), 0.05, 'leq');
```

```js
        const m = e.data;

        else if (m.type === 'reset') resetStats(this.state);

      const ch = inputs[0] && inputs[0][0];
      if (ch && processBlock(this.state, ch)) this.port.postMessage(readout(this.state));
```
